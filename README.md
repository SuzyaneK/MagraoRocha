# Wendel Rocha — Landing Page

Landing page desenvolvida para apresentar a trajetória e os serviços profissionais do meu pai **Wendel Fernandes (Magrão Rocha)** na área de **soldagem industrial**.

O projeto tem como objetivo criar uma presença digital, reunindo informações sobre sua experiência, áreas de atuação, conteúdos técnicos e canais de contato em uma única página.

🌐 **Acesse o projeto:** [magrao-rocha.vercel.app](https://magrao-rocha.vercel.app/)

---

## Sobre o projeto

O projeto foi criado utilizando **HTML e CSS**, com foco em uma apresentação simples e objetiva.

A página funciona como um portfólio profissional, permitindo que visitantes conheçam a experiência e as principais áreas de atuação de Wendel Fernandes, além de encontrarem facilmente seus conteúdos e meios de contato.

* **HTML5** — estrutura e organização do conteúdo;
* **CSS3** — estilização, layout e identidade visual;
* **Vercel** — hospedagem e publicação da aplicação.

O projeto está publicado utilizando a **Vercel**.
